# 达普生物仪器数据平台前端品牌重构实施记录

## 1. 实施目标

本次改造将现有 OpenRemote 前端统一为达普生物（DPBIO）的企业级仪器数据平台视觉体系。产品定位是汇集仪器运行数据、查看实时与历史状态、处理告警，并为后续 PyOD 异常检测建模提供清晰的数据观察界面。

本次只调整视觉层与品牌默认值，不新增 PyOD 功能，不修改数据结构、接口、路由、权限、表单字段、事件、页面入口或业务流程。

## 2. 设计方向

- 设计语言：专业、克制、精密、可信赖，避免模板化渐变、玻璃拟态和无意义装饰。
- 视觉密度：保持运维与数据分析产品所需的高信息密度，不把仪器页面改造成营销页。
- 层级方式：以留白、浅灰蓝底、细边界和少量阴影区分层级，深蓝只承担品牌和关键操作。
- 动效原则：仅保留 120 至 180 毫秒的状态反馈；用户启用“减少动态效果”时关闭非必要动画。
- 组件体系：继续使用项目已有 Lit、Vaadin/Lumo、Material Data Table 与 ECharts，不引入新的设计框架。

## 3. 品牌依据

品牌颜色取自 `达普品牌形象视觉识别手册_20250409_RGB.pdf`：

- 品牌主蓝：`#0215C1`
- 品牌亮蓝：`#0395FF`
- 品牌深海军蓝：`#000046`
- 品牌青色：`#00C8FF`
- 成功绿：`#8CC800`
- 警告黄：`#FFBE00`
- 危险红：`#E60050`
- 中性灰：`#D2D2D2`、`#969696`、`#4B4B4B`

Logo 使用从手册原始矢量路径提取的 SVG。桌面端使用完整 DPBIO 标志，移动端、favicon 与主屏图标使用独立图形标。标志未变形、描边、加阴影或重新设计。

字体优先使用品牌手册指定的 HarmonyOS Sans。本项目资料未包含可分发字体文件，因此采用本机字体优先的安全字体栈：HarmonyOS Sans SC、HarmonyOS Sans、Microsoft YaHei、PingFang SC、Segoe UI、Arial、sans-serif，不通过第三方 CDN 加载字体。

## 4. 主题系统

新增 `ui/component/theme/src/dpbio.css` 作为达普生物主题入口，并保留原主题结构与组件注入机制。

主题变量分为以下层次：

1. 原始品牌色：确保品牌主蓝、亮蓝、深海军蓝保持统一。
2. 产品表面色：画布、面板、次级面板、选中背景、边界与文本层级。
3. 操作色：主按钮、悬停、按下、焦点环与禁用状态。
4. 运行状态色：信息、成功、警告、错误及其前景色。
5. 数据序列色：为仪器遥测和异常分析提供八组稳定颜色。
6. 形状与层次：6、8、10、12 像素的克制圆角体系与两级轻阴影。

浅色模式以 `#F6F8FC` 为画布、白色为主要数据表面、`#000046` 为强标题色。暗色模式以 `#000046` 为画布、`#000064` 为面板、亮蓝为主要操作色。两种模式不混用不同的视觉语言。

## 5. 已实施范围

### 5.1 品牌入口

- Manager 默认标题改为“达普生物仪器数据平台”。
- Insights 默认标题改为“达普生物数据洞察”。
- Manager 与 Insights 统一注入品牌主题。
- 更新桌面 Logo、移动端 Logo、favicon、Apple 主屏图标与 Windows 磁贴图标。
- 部署配置中的 default、smartcity、manufacturer 三套默认视觉变量统一为达普品牌值，原页面与筛选配置保持不变。

### 5.2 导航与基础交互

- 调整 Logo 尺寸、导航间距、选中状态与分隔线。
- 为键盘焦点增加清晰的亮蓝焦点环。
- 主按钮使用深蓝底白字；暗色模式使用亮蓝底深海军蓝字。
- 对话框、徽标、复选框、开关统一使用主题变量。
- 加载动画沿用原有结构和时序，仅替换为达普蓝、亮蓝、青色。

### 5.3 数据工作区

- 表格统一白色数据面、浅灰蓝表头、细边界、行悬停和等宽数字特性。
- 资产树和树形菜单统一选中背景、品牌色指示条与键盘焦点。
- 资产查看器、配置页和管理页的面板统一背景、边界、圆角和轻阴影。
- 仪表盘编辑画布、网格线、部件边界与选中状态统一为品牌主题。

### 5.4 图表与仪表

- 折线图与柱状图共享八色遥测序列，序号含义保持稳定。
- 已显式配置的属性颜色继续优先，不会被默认品牌色覆盖。
- 图表背景、边界、网格线、坐标轴、文字和 Tooltip 支持浅色与暗色主题。
- 数据序列使用品牌色或同色相的可访问深色衍生值，避免黄、绿、浅灰直接画在白底上时辨识度不足。
- 仪表盘数字使用较稳定的字重和等宽数字；原阈值、最小值、最大值和实时更新逻辑不变。

### 5.5 告警与通知

- 告警状态与严重度枚举、文本、筛选和操作均保持不变。
- 已解决使用品牌绿，处理中与低等级使用亮蓝，中等级使用品牌黄，高等级使用品牌红。
- 亮蓝、黄、绿背景统一使用深海军蓝文字；危险红使用白字，确保语义与可读性同时成立。
- 通知“已送达”和“已发送”只替换为主题语义文字色。

## 6. 功能保护措施

- 未修改任何后端 Java 文件、数据库脚本或 API 定义。
- 未修改页面路由、导航标签、权限判断、Redux 状态结构或网络请求。
- 未修改表单字段名称、字段顺序、校验规则或提交事件。
- 未修改图表取数、时间范围、聚合方式、缩放行为或 Tooltip 内容计算。
- 未修改告警状态流转、通知状态、资产选择与仪器数据订阅。
- 所有新增默认值均允许既有 Realm 配置、组件变量和用户自定义颜色继续覆盖。

- 将默认界面语言设为简体中文，并把达普生物自定义仪表盘中的固定标题改为自然中文。
- 保留 CSV、GeoJSON、JavaScript、Groovy、Webhook 协议名称及 SI 单位等必要技术术语，避免为了“全中文”制造不准确译法。

### 10.2 术语规范

| 英文概念 | 统一中文 | 说明 |

| Asset | 设备 | 符合仪器运行数据采集场景，不使用含义宽泛的“资产”或“资源” |
| Realm | 租户 | 表达系统中的隔离组织空间，不直译为“领域” |
| Attribute | 属性 | 表示设备测点或配置属性 |
| Datapoint | 数据点 | 表示带时间戳的设备属性记录 |
| Agent | 接入代理 | 表示对接协议或外部系统的连接组件 |

| Alarm | 告警 | 采用工业监控系统常用表达 |
| Dashboard | 仪表盘 | 表示运行数据的可视化看板 |
| Insights | 数据分析 | 强调数据查看与分析用途，避免生硬直译 |

### 10.3 中文语义处理

- 将确认、删除、保存失败、权限限制、数据加载和连接状态等提示改写为符合中文操作习惯的完整句子。

- 中文不使用英文序数词后缀，因此周期计划中的 `st`、`nd`、`rd`、`th` 保持为空，由日期数字和中文句式共同表达。
- 所有插值变量、复数键和嵌套键均保持原结构，翻译不会改变业务参数、状态枚举或事件逻辑。
